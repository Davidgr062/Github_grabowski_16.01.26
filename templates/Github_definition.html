Was ist Github?

GitHub ist eine webbasierte Plattform, die auf dem Versionskontrollsystem Git basiert. Sie wird verwendet, um Code zu speichern, zu verwalten und gemeinsam an Softwareprojekten zu arbeiten.

Eigenschaften die Github zu einem der beliebtesten Progammiersoftwares macht:

  1. Kontrolle von Code
  2. optimale Zusammenarbeit im Team
  3. Hosting von Projekten (öffentlich oder privat)
  4. Speicherung jeder Version mit Zugriff

Wofür wird Github verwendet?

  1. Portfolio für alle vorherigen Projekte
  2. hauptsächlich als Projektmanager zwischen verschiedenen Abteilen des gleichen Projekts

Vokabular für die Arbeit mit Github

  • Git: Ein Versionskontrollsystem zur Nachverfolgung von Codeänderungen
  • GitHub: Eine Online-Plattform zum Hosten von Git-Repositories
  • Repository: Ein Projektordner mit Code und Versionsverlauf
  • Commit: Eine gespeicherte Änderung am Code
  • Push: Hochladen von Commits auf GitHub
  • Pull: Herunterladen von Änderungen von GitHub
